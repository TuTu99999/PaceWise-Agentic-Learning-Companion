# Phân tích thiết kế hệ thống thông tin

- `course`: lộ trình, mục tiêu đầu ra và phạm vi đánh giá
- `quizizz`: workbook 48 câu
- `exercises`: bài tập mô hình hóa và rubric
- `exams/midterm`: đề giữa kỳ kết hợp trắc nghiệm và tự luận
- `exams/final`: đề cuối kỳ kết hợp trắc nghiệm và tự luận

Phạm vi: SDLC, UML, Use Case, Class, Sequence, Communication, State Machine, Activity, Component và Deployment Diagram.
