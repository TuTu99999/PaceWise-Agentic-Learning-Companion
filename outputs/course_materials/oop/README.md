# Lập trình hướng đối tượng Java

Mã môn trong bộ demo là `OOPJAVA201`. Đây là môn Java, khác với `OOPCPP201` trong thư mục `object_oriented_programming`.

- `course`: lộ trình, mục tiêu đầu ra và bài tập theo buổi
- `quizizz`: workbook 48 câu Quizizz
- `exams/midterm/student`: đề giữa kỳ dành cho sinh viên
- `exams/midterm/teacher`: đáp án và rubric giữa kỳ
- `exams/final/student`: đề cuối kỳ dành cho sinh viên
- `exams/final/teacher`: đáp án và rubric cuối kỳ

Bộ 9 PDF slide Java đã được PaceWise nạp theo chương. Bài tập và rubric theo 12 buổi hiện nằm trong `course/hoc_lieu_oop_day_du.docx`, nhưng cùng file còn chứa phần đáp án giảng viên. Vì vậy loader chưa cấp nguyên file này cho student RAG; cần tách một bản bài tập sinh viên không có đáp án trước khi index.
