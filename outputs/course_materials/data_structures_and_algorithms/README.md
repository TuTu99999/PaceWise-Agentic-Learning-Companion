# Cấu trúc dữ liệu và giải thuật

- `course` : lộ trình 12 buổi và mục tiêu đầu ra
- `quizizz` : workbook import Quizizz 48 câu
- `exercises` : bài tập/lab và đáp án/rubric
- `exams/midterm` : đề giữa kỳ và đáp án/rubric
- `exams/final` : đề cuối kỳ và đáp án/rubric

Nguồn: 12 PDF slide do người dùng cung cấp. Đánh giá kết hợp trắc nghiệm, đọc mã, phân tích độ phức tạp, xử lý cấu trúc dữ liệu và cài đặt giải thuật tối ưu.
