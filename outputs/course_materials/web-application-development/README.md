# Phát triển ứng dụng Web

- course: lộ trình, mục tiêu đầu ra và phạm vi đánh giá
- quizizz: workbook 48 câu dùng để import và tra cứu
- exercises: bài tập 12 buổi cùng đáp án định hướng và rubric
- exams/midterm/student: đề giữa kỳ dành cho sinh viên
- exams/midterm/teacher: đáp án và rubric giữa kỳ
- exams/final/student: đề cuối kỳ dành cho sinh viên
- exams/final/teacher: đáp án và rubric cuối kỳ

Công nghệ: HTML, CSS, JavaScript, PHP, MySQL và PDO.
