# Hệ thống viễn thông

- `course`: lộ trình 12 buổi và mục tiêu đầu ra
- `quizizz`: workbook import Quizizz 48 câu
- `exercises`: bài tập và đáp án/rubric
- `exams/midterm`: đề giữa kỳ + đáp án/rubric
- `exams/final`: đề cuối kỳ + đáp án/rubric

Nguồn: 6 chương slide do người dùng cung cấp. Hình thức đánh giá được thiết kế kết hợp trắc nghiệm, tự luận và bài tính.
