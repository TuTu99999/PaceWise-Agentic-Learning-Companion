# Lập trình hướng đối tượng C++

Mã môn trong bộ demo là `OOPCPP201`. Đây là môn C++, khác với `OOPJAVA201` trong thư mục `oop`.

- `slides`: 12 PDF C++ đúng môn, đã được PaceWise nạp theo từng chương.
- `exams/midterm/student` và `exams/final/student`: đề C++ đúng môn.
- `course/hoc_lieu_Tri_tue_nhan_tao.docx`: sai môn, là học liệu Trí tuệ nhân tạo.
- `exercises/Lap_Trinh_Nhung_Va_He_Thong.docx`: sai môn, là bài tập Lập trình nhúng.
- Các file đáp án/rubric không được cấp cho student RAG.

Loader chỉ index 12 slide C++ và cố ý loại các file sai môn ở trên. Cần biên soạn lại bài tập C++ theo chương trước khi bật gợi ý bài tập cho Do/chatbot.
