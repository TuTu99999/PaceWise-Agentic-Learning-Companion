# PaceWise documentation

Thư mục này chỉ giữ tài liệu cần cho hồ sơ bàn giao PaceWise và bộ hướng dẫn
do Ban tổ chức cung cấp.

## Bộ hồ sơ bàn giao

Bộ hồ sơ theo 10 hạng mục cần chuẩn bị nằm tại
[`docs/deliverables`](deliverables/README.md):

1. mã nguồn;
2. README dự án;
3. sơ đồ kiến trúc;
4. đặc tả và thiết kế;
5. tài liệu kiểm thử;
6. nhật ký tuần;
7. Live URL;
8. Video Demo;
9. Pitch Deck;
10. AI Log — đã cập nhật trên hệ thống, không sao chép log vào repository.

Các tệp trong `deliverables` đóng vai trò mục lục bàn giao. Chúng liên kết tới
tài liệu nguồn đang được duy trì trong repository để tránh tạo các bản sao nhanh
chóng lỗi thời.
