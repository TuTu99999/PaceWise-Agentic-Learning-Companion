## Quy tắc bàn giao

- Không đưa `.env`, API key, token, cookie hoặc dữ liệu cá nhân vào hồ sơ.
- Source code được bàn giao bằng chính repository, không sao chép thêm một bản
  source vào `docs`.
- Video và slide có thể là file trong thư mục tương ứng hoặc một liên kết có
  quyền truy cập công khai.
- Chỉ đánh dấu Live URL là hoàn tất sau khi đã mở thử bằng phiên ẩn danh.
